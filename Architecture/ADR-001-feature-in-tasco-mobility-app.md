# ADR-001: Verified Vehicle Report as a feature inside the TASCO Mobility app

| Field | Value |
|---|---|
| Status | Accepted |
| Date | Lesson 4 |

**Context.** Car owners already use the TASCO Mobility app, and the project is a feature for that app. The owner needs to see the vehicle record and start the sale request in the same place.

**Decision.** Build Verified Vehicle Report as a feature inside the TASCO Mobility app. No separate app for car owners in this release.

**Consequences.** The owner reaches the report, the market price and the sale request from one app. The screens of Lesson 8 are screens of the TASCO Mobility app. The screens for Data Infrastructure Staff are on a separate staff website (see the architecture, presentation layer).
