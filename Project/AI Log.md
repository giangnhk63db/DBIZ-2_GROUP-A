# AI log: where AI suggested something wrong

Kept for the whole project. One entry each time an AI tool proposed something the team did not
accept, with the decision and where it was recorded. (UC = use case; ID = identifier.)

| # | Lesson | What AI suggested | Why it was wrong for the Market Price use case diagram | What the team did |
|---|---|---|---|---|
| 1 | L? (use case diagram) | Model the relationship between UC-2.10 (Backfill 12-Week Price History) and UC-2.06 (Sync 180-Day Listing History) as an `<<include>>`, implying the 180-day listing synchronization runs in every backfill run | UC-2.06 is required only when a newly added vehicle belongs to a car model that does not yet exist in the listing repository. When the model already exists, the backfill retrieves the stored listings directly and UC-2.06 is not executed. Since UC-2.06 is triggered conditionally and UC-2.10 can be completed without it, the relationship is optional and should be an `<<extend>>` | Revised to UC-2.06 `<<extend>>` UC-2.10, with the arrow directed from UC-2.06 to UC-2.10. Added the extension condition "for the 1st signed up car model" to the relationship so the trigger is explicit in the diagram. Cross-checked against the UC-2.10 specification, which states the 180-day synchronization is performed beforehand only if the car model is absent from the repository |
| 2 | L? (sequence diagram) | Generate Mermaid code for the sequence diagrams from the provided use case list, but the output paraphrased or shortened several use case names instead of keeping the original ones | The use case names were not yet consistent across the different diagrams when the sequence diagrams were generated, and there was no fixed list of names for the AI to follow, so it wrote its own shorter or reworded versions. The names in the sequence diagrams therefore did not match the original use case list | Verified each sequence diagram against its use case ID rather than by name alone, and compared it with the original use case list. Corrected every title or message that deviated from the official name manually in the Mermaid code. Every sequence diagram now carries the exact use case ID and name defined in the original list |
